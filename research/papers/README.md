# Статьи и бенчмарки про instruction-following и ограничения

Эта подборка помогает лучше понимать, **как LLM выполняют сложные инструкции**,
что происходит при росте числа ограничений, и почему «просто добавить ещё требований в промпт»
часто даёт деградацию качества.

## Подборка

1) **ComplexBench** — сложные инструкции с композицией ограничений  
   - [README](benchmarking-complex-instruction-following/README.md)

2) **IFScale** — сколько инструкций модель тянет одновременно  
   - [README](how-many-instructions-can-llms-follow/README.md)

3) **LSCG / Words Checker + FoCusNet** — сотни ограничений и выделение релевантных  
   - [README](large-scale-constraint-generation/README.md)

> Во всех папках: оригинальный PDF (EN) + русская версия (перевод аннотации + конспект ключевых идей).
