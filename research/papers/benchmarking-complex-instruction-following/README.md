# ComplexBench — Benchmarking Complex Instruction‑Following with Multiple Constraints Composition

**О чём:** бенчмарк для оценки того, как LLM следуют **сложным инструкциям**, где одновременно действуют
разные типы ограничений и есть **структура композиции** (например: AND‑ограничения + последовательные шаги + ветвление по условию).

## Почему это важно для AI‑First

В промышленной разработке мы часто формулируем «инструкции» как набор требований:
FR/NFR, ограничения по интерфейсам, стиль/формат, правила безопасности, критерии приёмки и т.д.

ComplexBench показывает, что проблема не только в количестве ограничений, но и в **их композиции**:
- **AND**: выполнить всё одновременно (формат + длина + стиль + безопасность…)
- **CHAIN**: сделать шаги по порядку (сначала A, затем B, затем C)
- **SELECTION**: выбрать ветку по условию (если X — делаем так, иначе — иначе)
- **NESTED**: комбинации вышеописанного

## Практические выводы

- Пишите требования **структурно** (список + шаги + ветвления), а не «одним абзацем».
- Разделяйте «что сделать» (задача) и «как должно выглядеть» (ограничения/контракт).
- Для проверки качества используйте **правила и тесты**: не полагайтесь только на «оценку LLM‑ом».
- Если есть ветвление (selection) — фиксируйте условие и явно просите **показать выбранную ветку**.
