# ComplexBench — перевод аннотации и конспект (RU)

## Перевод аннотации (смысловой)

Следование инструкциям — одна из базовых возможностей больших языковых моделей (LLM).
По мере роста их качества LLM всё чаще применяют для работы со сложными человеческими инструкциями
в реальных сценариях. Поэтому оценка способности LLM **следовать сложным инструкциям** становится критически важной.

Существующие бенчмарки в основном описывают разные типы ограничений в инструкциях, но
недооценивают **композицию ограничений** — неизбежную часть сложных инструкций.
Чтобы закрыть этот пробел, авторы предлагают **ComplexBench** — бенчмарк для комплексной оценки того,
как LLM следуют инструкциям, составленным из множества ограничений.

В работе вводится иерархическая таксономия сложных инструкций:
- **4 типа ограничений**
- **19 измерений (dimensions) ограничений**
- **4 типа композиции** (Single / And / Chain / Selection) + вложенные структуры

Датасет собран вручную. Для надёжной оценки авторы дополняют LLM‑оценщики правилами,
которые проверяют, удовлетворяет ли ответ каждому ограничению и композиции.
Итоговый балл агрегируется с учётом **структуры зависимостей**, заданной типом композиции.
ComplexBench выявляет заметные слабые места современных LLM при работе с такими инструкциями.

## Ключевые идеи, которые можно забрать в практику

1) **Композиция важна**: «AND + шаги + ветвление» труднее, чем просто список требований.  
2) **Оценка тоже должна быть структурной**: нельзя просто «усреднить галочки» — есть зависимости (например, шаги).  
3) **Rule‑augmented оценка** (правила + LLM‑оценщик) ближе к инженерной реальности: часть проверок должна быть детерминированной.

## Как применять в AI‑First разработке

- Формализуйте требования как **контракт**: входы/выходы, шаги, условия ветвления, критерии приёмки.
- Отдельно фиксируйте «ограничения формата» (формат/длина/язык), «семантики» (что должно быть сказано) и «utility/helpfulness» (тон, полезность, полнота).
- Для интеграции в pipeline делайте упор на **quality gates**: тесты/линтеры/проверки формата/бенчмарки.
