# Шаблоны SDD

SDD (Spec‑Driven Development) — инженерный контур AI‑First, который делает работу с ИИ:

- управляемой (через нормы и policy‑as‑code),
- проверяемой (через quality gates),
- воспроизводимой (через версии артефактов и отчёты).

В этой папке — минимальные шаблоны для запуска контура.

## Содержимое

- `sot/` — Source of Truth (SoT‑0): устойчивые нормы проекта.
- `policy/` — машиночитаемые политики (пример gates).
- `specs/` — требования (AR), решения (ADR), модульный дизайн (MOD) — как шаблоны.
- `reports/` — шаблоны отчётов (REP‑GATE).

См. также: [SDD: методические указания](../../docs/methodology/sdd-methodical-guidelines.md)
