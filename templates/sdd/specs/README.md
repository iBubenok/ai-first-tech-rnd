# Шаблоны спецификаций

- `AR-template.md` — требования и критерии приёмки (Acceptance Requirements).
- `ADR-template.md` — архитектурное решение (Architecture Decision Record).
- `MOD-template.md` — модульный дизайн (границы, контракты, инварианты).

Шаблоны соответствуют мини‑скелетам из приложения A в документе SDD.
