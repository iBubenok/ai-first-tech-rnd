# QUALITY_BAR (SoT‑0)

> **Статус:** шаблон

Порог качества — это минимальные требования, которые должны выполняться до принятия изменений.

## 1) Definition of Done (DoD)

- Код компилируется/собирается без ошибок.
- Добавлены/обновлены тесты.
- Пройдены линтеры и статический анализ.
- Документация обновлена (если изменение влияет на интерфейсы/поведение).

## 2) Метрики качества (пример)

- Покрытие тестами: ≥ …%
- P0/P1 дефекты: 0
- Производительность: не хуже baseline более чем на …%

## 3) Минимальные проверки

- Unit tests
- Integration tests (если применимо)
- Static analysis
- Security scan (если применимо)

## 4) Исключения

Любые исключения должны быть оформлены в gate‑отчёте (REP‑GATE) с обоснованием и сроком снятия.
