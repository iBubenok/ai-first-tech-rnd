# SoT‑0 (нормы проекта)

Эти документы задают «законы проекта» — устойчивые нормы, которые должен соблюдать и человек, и ИИ.

Рекомендуемый минимум:

- `CONSTITUTION.md` — конституция проекта (что делаем и как принимаем решения).
- `GLOSSARY.md` — глоссарий домена.
- `ARCH_BASELINE.md` — базовая карта архитектуры.
- `QUALITY_BAR.md` — пороги качества и Definition of Done.
- `SECURITY_BAR.md` — пороги безопасности и правила обращения с данными.
- `AI_USAGE_POLICY.md` — правила использования AI/LLM‑инструментов.
- `REPO_LAYOUT_STANDARD.md` — стандарт структуры репозитория и артефактов.
