# Шаблоны (templates)

Шаблоны помогают быстро запустить AI‑First контур и стандартизировать артефакты.

## Что внутри

- [`templates/sdd/`](sdd/) — шаблоны для Spec‑Driven Development (SoT, policy‑as‑code, отчёты gate’ов, требования).
- [`templates/initiative/`](initiative/) — шаблоны для инициатив (описание, гипотезы, метрики, план внедрения).
- [`templates/licenses/`](licenses/) — шаблоны текстов лицензий/правовых оговорок (при необходимости).

> Шаблоны — это стартовая точка. Адаптируйте под ваш домен, процессы и требования безопасности.
