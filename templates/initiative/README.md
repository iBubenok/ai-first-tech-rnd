# Шаблоны для инициатив

Инициатива — это конкретное направление внедрения AI‑First (продукт, домен, команда или платформа).

Рекомендуемый минимум артефактов инициативы:

- `README.md` — краткое описание инициативы и навигация.
- `concept.md` — концепция применения AI‑First в домене.
- `implementation-plan.md` — план внедрения (этапы, KPI, риски, артефакты).

В этой папке — стартовые шаблоны, которые можно копировать в `initiatives/<name>/`.
