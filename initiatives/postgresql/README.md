# Инициатива: AI‑First для PostgreSQL‑ориентированной СУБД

Материалы инициативы описывают концепцию и план мероприятий по внедрению подхода **AI‑First**
в процесс разработки и эксплуатации СУБД на базе PostgreSQL.

Фокус: сценарии с высокими требованиями к безопасности, импортонезависимости и интеграции
в корпоративные/промышленные платформы, включая работу в защищённых или изолированных контурах.

## Что внутри

- [Концепция AI‑First для PostgreSQL‑СУБД](concept.md)
- [План внедрения](implementation-plan.md)

## Как использовать

1) Начните с концепции, чтобы согласовать цели, принципы и целевую архитектуру.
2) Затем используйте план внедрения как дорожную карту: подготовка → пилот → масштабирование → институционализация.
3) Сопоставьте этапы с общими правилами репозитория: [политика данных](../../docs/policies/data-policy-and-security.md) и [SDD](../../docs/methodology/sdd-methodical-guidelines.md).
