# Инициативы (initiatives)

Этот раздел содержит материалы, привязанные к конкретным направлениям, продуктам или доменам.
Как правило, внутри инициативы есть:

- концепция AI‑First применения;
- план внедрения (этапы, артефакты, KPI, риски);
- дополнительные материалы (по мере появления).
