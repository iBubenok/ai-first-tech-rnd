# Плейбуки (playbooks)

Плейбук — это практическая инструкция «как делать»:

- как запускать AI‑First в команде;
- как выбирать пилоты;
- как мерить эффект;
- как устраивать quality gates;
- как безопасно работать с данными;
- как масштабировать на несколько команд.

Если у вас есть опыт, который уже повторялся более одного раза — оформляйте его плейбуком.
