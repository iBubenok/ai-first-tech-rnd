# Knowledge transfer

Раздел для материалов обучающих сессий (слайды, сценарии, конспекты, Q&A).

## Как добавлять

Создавайте папку по формату:

- `YYYY-MM-topic/` (например, `2026-03-sdd-gates/`)

Внутри:

- `README.md` — цель сессии, аудитория, как использовать материалы;
- `slides.pptx` или `slides.pdf` — слайды;
- опционально: `notes.md`, `demo/`, `links.md`.

## Требования

- Без исходников, приватных спецификаций и любых чувствительных данных.
- Без внутренних URL/адресов/имен систем.
