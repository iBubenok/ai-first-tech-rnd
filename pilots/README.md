# Пилоты (pilots)

Пилоты — это управляемые эксперименты, которые проверяют гипотезы AI‑First на реальных задачах.

## Рекомендуемая структура пилота

Создавайте папку `YYYY-MM-pilot-name/` и добавляйте:

- `README.md` — цель пилота, команда, сроки;
- **гипотезы** и **метрики** (baseline → target);
- список артефактов (SoT, gates, отчёты);
- результаты: что получилось, что не получилось, выводы, решения по масштабированию.

## Важно

Пилот считается успешным только при наличии измеримого эффекта и воспроизводимого процесса,
а не по субъективному впечатлению.
