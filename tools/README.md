# Tools

Раздел для утилит и скриптов, которые поддерживают практики AI‑First:

- проверки документов (lint/validation);
- генерация context packs;
- трассируемость (AR → ADR → MOD → тесты/отчёты);
- санитизация/безопасный экспорт материалов.

Если вы добавляете инструмент:

- держите рядом `README.md` с назначением и примером запуска;
- добавляйте минимальные тесты/пример входных данных;
- избегайте зависимости от внутренней инфраструктуры.
